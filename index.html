pipeline

Zero copy-paste. One input, five outputs.

01 — RESEARCH
Find the signal
Queries web for funding, hiring, and launch activity — not generic search results.
02 — OUTREACH
Write from findings
Connection request and cold email use what was actually found, not a template.
03 — SCORE
Rank by fixed rules
Stage, funding, hiring add to 0–100. LLM explains, doesn't invent the score.
04 — CRM
Log it, once
Writes to Google Sheet with status. Same prospect won't be saved twice.
features

Built for someone who has to send the next 50 messages.

[ 01 ]

Real-time research

Two targeted Serper queries — company news + person profile. Not generic search noise.

[ 02 ]

Connection + cold email

Both in one run, capped at 50 words for the request so it doesn't get truncated on LinkedIn.

[ 03 ]

Follow-up message

Generated separately. Leads with value instead of restating the original pitch.

[ 04 ]

Duplicate-safe CRM

Checks name + company before writing a row. Same prospect won't pile up in the sheet.

[ 05 ]

Status pipeline

New → Contacted → Replied → Meeting Booked → Won / Lost, tracked per CRM row.

[ 06 ]

Live analytics

Outreach count, reply rate, and hot-lead count pulled from the sheet — not hardcoded.
